# Lyst

A minimal, mobile-first personal list app with offline support, natural-language parsing, and AI assistance.

## Features

- Personal lists with Firestore sync
- Offline-first PWA support
- Natural-language dates and quantities
- AI list generation, suggestions, and cleanup
- Firebase Authentication and per-user AI limits

## Built with

React · Vite · Firebase · Cloudflare Workers · Gemini
